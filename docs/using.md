# 怎么用

搭档——一个只服务你一个人的助手。下面写给第一次用的人。不谈架构，只说从装好到第一件事做完要走的几步。

## 1. 装上（约两分钟）

```sh
node scripts/install.mjs --profile personal --port 3082
```

它建一个独立的 DSH profile，装好这个 agent，并把该配的都配上（包括 worker 的权限——漏了这一步，活会卡在等审批）。

默认装进 `~/.dsh`（设了 `DSH_HOME` 就听它的）。要把助手装到别的主目录，加 `--home`：

```sh
node scripts/install.mjs --profile personal --port 3082 --home ~/.dsh-work
```

profile、它的状态目录、还有 `.credentials.yaml` 都跟着这个 home 走——换一个 home 就是另一个互不相干的助手，密钥也要重新给（见第 2 步）。

脚本默认把它自己所在的这份代码装进去。要装别的包——发出来的 tarball、或本地另一份构建产物——用 `--bundle` 指过去：

```sh
node scripts/install.mjs --profile personal --port 3082 \
  --bundle https://github.com/yinguobing/dsh-personal-agent/releases/download/v0.10.0/dsh-personal-agent-0.10.0.tgz
```

本机路径（`./` 开头或绝对路径）按本地目录装，其余原样交给 `dsh plugin add`。

## 2. 给一个模型密钥

安装脚本会检查。没有的话，它会把命令直接给你：

```sh
cp ~/.dsh/.credentials.yaml ~/.dsh/../<你的 home>/.credentials.yaml
```

没有密钥时，**它会收下你的话但答不上来**——面板会说明，微信会收到一条「没能处理完」。

## 3. 启动

```sh
DSH_HOME=<你的 home> dsh --profile personal
```

它会打印一个带 token 的地址。打开，点侧栏的 **Superagent**。

## 4. 你看到的第一屏

一整个对话，从中间滚到底部，输入框钉在最下面。

你托付的事不是列表，而是对话里的卡片：正在做的和最近两天做完的排在最后，状态写成「在做」「等你过目」「做完了」。需要你拍板的（它的问题、它想做的建议）以卡片浮在输入框上方——因为你就在那儿回答。

点开一张卡片，看到的是三样东西：**它做了什么**（每一步的报告，人话）、**结果**（产出的文件，可以直接展开看正文）、以及三个动作——改一下、再做一版、关闭。

右上角一个齿轮。点它是工程师的六个标签页（来源、触发、评估、执行、设置），默认不出现，开关记在浏览器里。

## 5. 第一件事

面板顶部是「跟我说」。不知道说什么的话，空状态里有三条例子，点一条就填进输入框。

发出去之后：

1. 它先回一句「已受理」；
2. 票出现在「待处理工单」，worker 开始干活；
3. 需要你决定时，问题回到这条对话里——**一次一个**；
4. 干完把结果贴回来，文件放在票据目录的 `drafts/` 下。

## 6. 让它自己看见东西

把文件丢进 `<stateDir>/inbox`（面板空状态里写着完整路径）。

**丢进去不等于交办。** 它会按规则判断：

- 觉得该做 → 在「我想做的」里出现一条，一句话说明我想干什么；
- 你点「去做吧」，我才开工；点「不用了」，这条就过去。

这是 `observe` 模式：**它会判断、会记录，但不替你决定。**

## 7. 每天一条摘要

默认早上 8 点（`digestHour`），一条消息说清：等你处理几件、进行中几件、昨天完成几件。

**没事就不发。** 发过的日子记在库里，重启不会重发。那小时里恰好没事，当天就不发。

## 8. 手机上用（可选）

需要先用 `dsh-weixin-login` 扫码登录一个机器人账号，再在 profile 里启用 `dsh-superagent-weixin`。

之后：微信发消息 → 它回执 → 需要你决定时把问题发到微信 → 你回一句 → 结果也发回微信。

## 几条你该知道的规矩

- **它不会替你对外说话。** 医疗、法律、财务材料只整理不判断；所有对外动作先出草稿。
- **写作时缺的东西它会留空。** 写成 `[待补: …]` 并在报告里列出来，不会编。
- **worker 只能写自己的票据目录。** 想让它改别处，得你自己动手或改权限。
- **一条消息一件事。** 连发两条会开两张票；回答提问才会续到原票上。

装不上、答不出、结果不对——看 [known-gaps.md](known-gaps.md)，那里列着已知不牢的地方。
